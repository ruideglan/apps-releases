# Apps Releases (OTA Centralizado)

Repositório centralizado de releases e atualizações Over-The-Air (OTA) dos aplicativos da plataforma Lucena Digital.

## Manifesto Central

O manifesto de controle de versão é [`version.json`](./version.json), consultado pelos aplicativos em tempo de execução para verificar a disponibilidade de novas atualizações.

### Aplicativos Mapeados
- **Nutreiner** (`com.nutreiner`)
- **Agendê** (`com.agende`)
- **Lumi Idiomas** (`com.lumi.idiomas`)
- **Lumi Números** (`com.lumi.numeros`)
